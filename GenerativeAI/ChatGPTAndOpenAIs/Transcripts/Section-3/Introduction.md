## Intoduction
### Summary

In this course on complete generative AI with Lang Chen Ecosystem, we will focus on building advanced generative AI applications and cover topics like NLP, deep learning, LM models, Lang chain ecosystem, fine tuning techniques, deployment techniques, and more.

### Highlights

* 🐍 Python programming language is covered extensively
* 🤖 NLP topics include RNN, LSTM, GRU, bidirectional RNN, encoder-decoder, attention mechanisms, Transformer, and Bert.
* 📚 Lang chain ecosystem offers a wide range of functionalities for developing generative AI applications with both paid and open source LM models.
* 🚀 Deployment techniques use free resources like Streamlit, while fine tuning techniques involve Google Colab and open source LM models.
* ☁️ AWS and Nvidia Nim modules allow for deploying generative AI applications in the cloud using AWS services and open source models.
* 💡 Crew Eye library helps create multi-agent applications for solving various generative AI tasks, in addition to working with Lang Chain and other frameworks.
