# ✅ Quick Start Checklist

Complete these 5 actions first — each takes under 5 minutes.

- [ ] (~2 min) Confirm your computer has 8GB+ RAM and 20GB+ free disk space
- [ ] (~3 min) Go to https://ollama.com and download the installer
- [ ] (~2 min) Install Ollama by running the downloaded file
- [ ] (~4 min) Open Terminal and run: `ollama run phi3`
- [ ] (~1 min) Type "hello" — when the AI responds, you have a working local AI
