# Part 3 — Learning Path

Work through these in order. Each resource builds on the previous one.

---

## 🟢 Beginner Level

### 1. How Computers Work (Optional — 50 min)
- **Resource:** CrashCourse Computer Science, Episodes 1–5
- **Where:** YouTube → search "CrashCourse Computer Science"
- **Why:** Gives you mental models for CPU, RAM, and storage before you touch AI
- **Action:** Watch while taking notes. Sketch a diagram of how CPU, RAM, GPU, and storage connect

---

### 2. Set Up Your Local AI Environment (1–2 hours)
- **Resource:** Ollama Official Docs
- **Where:** https://ollama.com/docs
- **Why:** Beginner-friendly. Covers Mac, Windows, Linux installation
- **Action:** Follow along and complete Part 4 of this guide (setup sessions)

- **Resource (video):** "Getting Started with Ollama" by Matthew Berman
- **Where:** YouTube → search "Matthew Berman Ollama beginner"
- **Why:** Video walkthrough — install, download models, chat. No coding needed
- **Action:** Watch first, then repeat the steps yourself without the video

---

### 3. LM Studio — Graphical Interface (Optional — 30 min)
- **Resource:** LM Studio built-in tutorials
- **Where:** https://lmstudio.ai
- **Why:** If the command line feels scary, LM Studio gives you a ChatGPT-like UI for local models
- **Action:** Download LM Studio, load a model, have a conversation. Compare it to Ollama in terminal

---

## 🟡 Beginner-Intermediate Level

### 4. Python Basics for AI Projects (10–20 hours)
- **Resource:** "Python for Everybody" — Dr. Chuck Severance, University of Michigan
- **Where:** https://coursera.org/specializations/python (click "Audit" — it's free)
- **Why:** Most beginner-friendly Python course available. No math required
- **Action:** Complete Chapters 1–4 (variables, loops, functions, files). Skip the graded assignments if auditing — just watch and code along

- **Resource:** Python Official Tutorial (reference)
- **Where:** https://docs.python.org/3/tutorial
- **Why:** Use this to look things up as you need them — don't read it front to back

- **Hands-on practice:**
  - Write a script that asks for your name and prints "Hello, [name]!"
  - Write a script that reads a text file and prints each line
  - Write a script that counts how many words are in a sentence

---

### 5. How AI Models Actually Work (1–2 hours)
- **Resource:** "But what is a neural network?" — 3Blue1Brown
- **Where:** YouTube → search "3Blue1Brown neural networks"
- **Why:** Beautiful visual explanations. No math prerequisites. Builds intuition for why models behave the way they do
- **Action:** Watch the first 3 videos in the series. Pause and re-watch any section that's unclear

---

### 6. Build a Local Personal Assistant (2–4 hours)
- **Resource:** "Build a Local AI Assistant with Ollama + Python"
- **Where:** YouTube → search "Ollama Python local assistant"
- **Why:** Shows how to connect Python to Ollama to build a chatbot that runs offline
- **Action:** Code along. Then modify the script: change the AI's personality, add a greeting message, save responses to a file

---

## 🟠 Intermediate Level

### 7. LangChain for AI Agents (4–8 hours)
- **Resource:** LangChain Official Beginner Tutorials
- **Where:** https://python.langchain.com/docs/get_started
- **Why:** LangChain is the most popular library for building AI agents. Tutorials start from zero
- **Action:** Complete the "Build a Simple LLM Application" tutorial using Ollama as the model

- **Resource (video):** "LangChain Crash Course" by Patrick Loeber
- **Where:** YouTube → search "LangChain crash course Patrick Loeber"
- **Why:** Practical, code-along video covering agents, tools, and memory in ~2 hours
- **Action:** Watch and code along. Build the examples yourself. Then try changing one thing in each example

---

### 8. AutoGen for Multi-Agent Automation (4–6 hours)
- **Resource:** AutoGen Official Documentation
- **Where:** https://microsoft.github.io/autogen
- **Why:** Microsoft's framework for multiple AI agents that collaborate on complex tasks
- **Action:** Complete the "Getting Started" tutorial. Build a two-agent conversation where one agent writes code and another reviews it
