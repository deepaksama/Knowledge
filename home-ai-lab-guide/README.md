No prior AI/ML knowledge required. Everything runs offline on your own hardware.

## 🎯 What You Will Build

By the end of 12 weeks, you will have built and be able to explain:

1. **A local AI environment** — multiple open-source models running on your machine
2. **A personal AI assistant** — named, with memory, voice input and output
3. **A task automation agent** — reads files, writes output, completes multi-step tasks

All running locally. No internet required. No API costs. No subscriptions.

---

## 🔧 Tools Used

- [Ollama](https://ollama.com) — run AI models locally
- [Python 3](https://python.org) — scripting and automation
- [LangChain](https://python.langchain.com) — AI agent framework
- [Whisper](https://github.com/openai/whisper) — offline speech-to-text
- [pyttsx3](https://pypi.org/project/pyttsx3/) — offline text-to-speech
- [ChromaDB](https://www.trychroma.com) — local vector database for RAG
